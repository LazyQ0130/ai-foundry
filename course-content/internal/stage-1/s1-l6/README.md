## 本次自拟需求与复述

以下是作者为内部验证选择的具体需求，不是发布给学生的完整 Prompt，也不是外部工具盲测。

A：用户想按日期浏览资料；选择默认、最新或最早后，当前资料按相应顺序展示；要与搜索、标签和重要筛选一起工作；原数据、统计和筛选行为保持不变。沿用现有样式，不新增依赖，不执行 Git 操作。

B：用户想一次退出组合筛选；点击后搜索清空、标签全部、重要关闭，卡片与统计同步恢复；已有空结果和重复点击也能正常处理；保留个人标题、资料及其他功能，不新增依赖，不执行 Git 操作。

按照正文先复述不修改。当前 Codex 在本轮对话中只读确认：A 排序当前结果并能恢复默认；B 清除三个条件并同步结果。`readonly-before.json` 和 `readonly-after.json` 记录页面、数据、依赖及 B 统计组件的 SHA256，全部相同。随后进入实现阶段。

这证明本轮 Codex 的实际执行结果，不代表所有模型必然遵守，也不能替代 WorkBuddy 实测。
