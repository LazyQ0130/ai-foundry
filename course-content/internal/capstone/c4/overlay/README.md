# Capstone C4 internal teaching overlay

Apply only after Bootstrap + C1 + C2 + C3 via `scripts/assemble-capstone-reference.mjs c4`. The student starts from their own C3 project; this overlay is an author validation reference. It adds one bounded retrieve-once/generate-once ResearchRun, structured GroundedReport, durable Citation snapshots, a shared retrieval service and minimal report UI. It intentionally contains no Agent workflow, tools, MCP or approval system.
