# Capstone internal references

Student bootstrap: `starter/capstone`. This tree holds author references and evidence, never the student starting product. Assemble C1/C2 into a fresh `.runtime` directory with `node scripts/assemble-capstone-reference.mjs c1|c2 <output>`.

The nine lesson plan is C1 product definition, C2 architecture and first slice, C3 file knowledge, C4 grounded report, C5 research workflow, C6 external research, C7 controlled write, C8 product verification, C9 delivery. Only C1/C2 author spikes exist in Phase 2. No formal lesson text is published here.
