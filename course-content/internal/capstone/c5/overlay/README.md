# Capstone C5 internal teaching overlay

Assemble after Bootstrap + C1 + C2 + C3 + C4. Students continue their own C4 project; this overlay is an author validation reference. It adds a bounded read-only Research Workflow, persistent Step Timeline and explicit cancellation while preserving C4 GroundedReport/Citation. It intentionally has no external research, write tool, approval, note, resume, worker or queue.
