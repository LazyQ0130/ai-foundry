# Phase 0 对课程研发蓝图V1.1的调整建议

日期：2026-10-14。状态：建议稿；原蓝图[blueprint-v1.1.md](inputs/blueprint-v1.1.md)保持不变。本轮只完成技术验证和文档，未开发P1–P8正文、Starter或Reference。当前[最终报告](evidence.md)技术闸门GO，正式产品尚未发布。

| 蓝图位置/课程 | 必要调整 | Phase0依据与后续边界 |
|---|---|---|
| §2权限路径、P1 | 明确采用普通action回调同步打开Side Panel，显式关闭openPanelOnActionClick自动行为；更新/启动时覆盖旧配置 | Chrome155自动侧栏分支绕过grant已实际失败并修复；不能只说“侧栏打开即获得activeTab”。保留真实图标验收 |
| §2版本、P1/P8 | 分开记录manifest目标下限与实际支持验证范围；独立lockfile/Node环境 | 实测Chrome155、Node24.16/npm11.13、WXT0.21.4；116下限未实测。冻结教材前再确定承诺范围，不把版本表等同兼容矩阵 |
| §3生命周期、§4 PageSnapshot、P2 | 在tabId/URL之外保留独立导航代次；异步前后核对requestId/snapshotId和上下文，切页取消/丢弃旧响应 | 同URL刷新、A→B→A不能只比较最终URL；0.0.2代次UUID存session跨worker重建，真正导航失效。未来blocks/blockId契约仍需独立冻结，不把Phase0 text字段直接当最终Schema |
| §2网络权限、P3 | 分别解释activeTab、host权限、CORS、CSP；当前回环API在Chrome155下新增host权限为0 | 精确扩展Origin+CSP固定127.0.0.1:8787已完成真实网络和原生侧栏验证。后端来源变化必须重新验证，不能直接增加全站权限或放行空Origin |
| §4模型API、P3/P5 | 真实Provider接入时同步扩展固定mock的响应判别字段、错误模型与验证器，保留共享Schema和服务端再次校验 | Phase0 SummaryResponse的provider只允许mock，接口职责已分离但不能无改动切真实供应商；真模型输出/引用/拒答/费用/提示注入评估未测，仍属未来授权阶段 |
| §4消息、P4 | 明确window/tab/URL/代次归属、60秒有效期、2000字符、最新事件覆盖及一次消费；拒绝空/长/子框架来源时覆盖旧槽位 | 已有自动边界及两站点人工证据；讲清有效期是使用时校验，不等于定时删除。选区session保存文字/来源，需单独说明隐私 |
| §4 Note、P7 | 把临时快照/选区与持久笔记分开，定义保留、删除、导出和存储预算 | 当前未做笔记/搜索/云同步；不能把session临时状态算成持久知识库完成 |
| §6/§10、P8 | 证据分层：截图、明确人工文字、真实HTTP/Chrome夹具、测试替身；自动测试与人工smoke分别记录 | 本轮44项测试不替代原生操作；独立Profile、完整重开、无DevTools空闲与重载均保留。假确认撤回时保留更正，不覆盖历史。条件允许时增加关键竞态录屏 |
| §7课程材料 | 未来每课以同一锁定环境和增量契约连续衔接；共享底层授权/代次/消息校验不在各课重复发明 | 此处只是建议，未生成正式课程、Starter业务代码或P1–P8 Reference。Mock起步后再逐步扩展完整产品 |
| §9平台接入 | 沿用独立projectSlug/lesson/check维度和原权益边界，维持Stage/Capstone分母与授权 | 本轮无需平台接入，未更改现有教学内容、数据库、权益、价格或发布状态；平台迁移需未来另行实施验收 |

后续研发应以原蓝图和这些实测修正作为设计输入；Phase0 GO只允许得出技术路线可继续的结论，是否启动下一阶段由用户后续任务决定。T01–T36全产品质量、真实Provider与正式发布仍未执行。
