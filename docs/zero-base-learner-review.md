## 一、总体判断

**这套课程的"AI 代写、你验收"模式确实把"看懂代码"的门槛降到了极低水平——但对"很少使用电脑"的读者，真正的门槛不在概念讲解，而在课程没有教的电脑操作。**

三处最陡的断崖（s2-l3 注册云数据库、s3-l4 安装 Docker + 连数据库、s4-l4 启动 MCP 服务）全部属于"本机人工操作"——恰好是 AI 帮不上忙、只能读者自己点鼠标的环节。课程的生存法则是"照抄约定 → 让 AI 写 → 刷新页面看结果"，这条法则在概念讲解层面几乎无往不利（读者看不懂 NDJSON、HMAC、cosine distance 也能过），但在上述三处会整体失灵。

Stage 1 的教学设计质量是全站最高的（「先搞懂」块、门牌号/发动机类比、stuck 排查、预期管理都到位），能以接近零基础可达；Stage 2 起概念密度和操作密度同时上升，每阶段第 3~4 课出现可预测的"密度峰值"；Stage 3 第 4 课是全程最陡的一课。

## 三、逐部分发现

### 3.1 环境说明页 + 第 0 课（入口）

环境页 `Environment.tsx` 的「工具与安装」节是第 0 课全部操作的地基，但对小白不够手把手：

1. 🟡 **「AI 开发工具」安装只有一句**："Stage 1 推荐使用 WorkBuddy 官方下载页"。没有说明这是什么软件、装完第一步点哪、怎么登录、界面长什么样。第 0 课所有操作（打开文件夹、发 Prompt、看 Diff）都依赖它，入口却最简略。
2. 🟡 **「安装当前 LTS，并保留 npm」**（环境页 L13）："保留 npm"指安装向导里的复选框，小白不知道那是什么；"历史最低版本是 18.18"对不会看版本号的人无意义。
3. 🟡 **Chat/Embedding 配置区术语密度极高**（Provider、Base URL、Workspace、地域、兼容接口、`NEXT_PUBLIC_` 前缀、维度）。这些是 Stage 2/3 才用的，但小白在第 0 课滚屏就会看到，容易恐慌。建议页首加一句"第 0 课只需看『工具与安装』，其余配置后续阶段才用到"。

第 0 课正文（s1-l0.md）质量高（类比得当：端口=门牌号、终端=发动机；反错位提醒到位："这一步输入的是地址，不是终端命令"），遗留问题：

4. 🟡 **Ctrl+C 双重含义陷阱**：L181 教"需要主动停止时按 `Ctrl+C`"，但从未警告终端里 Ctrl+C 是"停止程序"而非"复制"。小白想把终端里的红色报错复制出来发给别人时，按 Ctrl+C 会直接把 dev 服务器关掉——这是零基础最经典的事故，全站无一处提示。
5. 🟡 **cd 的引号**：L122 教"cd，空一格，把路径放在英文双引号内"，但没解释为什么（路径含空格时漏引号必失败）。照做能过，漏一步就卡，且不知道自己错在哪。
6. 🟢 打开 PowerShell"从开始菜单搜索"会出来多个结果（Windows PowerShell / PowerShell ISE / Windows Terminal），小白可能点错开 ISE。
7. 🟢 "网盘同步目录可能在安装时占用文件"（L108）——"网盘同步目录"对不知道自己装没装 OneDrive/坚果云的人是黑话。
8. 🟢 `localhost:3000` 输入地址栏：现代浏览器地址栏与搜索框合一，建议一句提醒"确认输入到地址栏，不要输入成搜索"。文中带 `http://` 前缀已部分缓解。

### 3.2 Stage 1（1.1～1.6）

Stage 1 整体是四阶段中对小白最友好的，无阻断级问题。逐课：

**1.1（改标题）**——🟢
- L104 一段内同时出现 Next.js、React、TypeScript、Tailwind CSS 四个名字，虽都标注"不用学"，认知噪音仍在；JSX 的处理反而好（"这一段文字对应刚才的大标题"）。
- 🟡 L94 "按 F5 或 `Ctrl+R` 刷新"：**刷新是什么、为什么要刷新从未解释**；且从这里开始全站只剩 Windows 键位——第 0 课有 Windows/macOS 双轨，1.1 起 macOS 读者再无 Cmd+R 出现。

**1.2（重要筛选）**——🟡
- **F12 → Console 是全 Stage 1 最陡的操作**（L212）：小白按下 F12 打开的是整个开发者工具面板，要在顶部一排英文标签里找到 Console。正文只说"切到 Console（控制台）"，没有说 Console 在面板顶部标签栏里找。macOS 对应键位（Cmd+Option+I）全站无一处提及。
- "状态/事件"概念解释质量高（"页面当前需要记住的一点信息"）；useState 的"不用急着学怎么写"处理得当；"结果为空，这不一定是哪里坏了"的预期管理很好。

**1.3（Debug 练习）**——🟡
- 全 Stage 1 流程确定性最低的一课：让 AI"故意造 Bug 且不告诉我原因"高度依赖 AI 配合度。若 AI 制造的现象不符合约定，小白几乎无自查能力（stuck 块给了可复制的纠偏指令，算重要缓解）。
- `&&`/`||` 的解释（"两边都要满足"/"满足其中一边就行"）和"复现=把问题再做出来"的表述是典范级的。

**1.4（统计与 Diff）**——🟢
- Diff 红绿含义解释好，且警告"不要把绿色理解为肯定正确"（L133）。变量名用"参考写法"框定，避免死抠。

**1.5（Git）**——🟡
- **L52 "另开一个项目终端"没有说：新开的终端默认不在项目目录，必须重新 cd。** 小白在新终端直接敲 `git status` 会得到 `not a git repository`。stuck 块有兜底，但一句前置说明能省掉整个困惑。
- 六个 Git 命令（init/status/add/commit/log/restore）一课全出，密度大；好在每个都有"先理解成"式解释，且明说"不用背"。Git 三条澄清（commit ≠ 上传、LF/CRLF 提示、Author identity）覆盖到位，质量高。

**1.6（综合练习）**——🟢
- 脚手架撤离设计合理（"不再给你完整 Prompt"），四问框架给了抓手，"登录、上传、数据库、云同步都超出范围"的划界清楚。
