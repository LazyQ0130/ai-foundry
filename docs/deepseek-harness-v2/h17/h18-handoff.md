# H18 前置与边界交接

H17只完成事件溯源、Surface、deriveMessages、请求/工具历史及基础Projection。下一课正式题目与范围仍由30讲蓝图决定：持久化后端、SessionHandle、只读重建/恢复执行/Fork、日志完整性与中断尾处理。本文件只是前置说明，不开发H18。

建议带入三件已有材料：D两份请求前缀和完整工具call/result；X确定性16条日志及被遮蔽的用户3；A的append成功/无后端flush=false/仅计数器flush=true对照。前两件证明读模型可重建，第三件说明还没有耐久性保证。

学员应能先手算[2,15,6,8,12]、最终5条消息、任务completed/1/1，并指出原16与重建17条的不同。再从长度与包含Seq换算读边界，不把Fork参数想成任意数组切片。完整Fork规则、继承切点和合成闭合本课未实验。

H18需回答：后端何时创建/打开句柄？flush实际承诺什么？谁拥有写入权？怎样区分历史回放与继续执行？有call缺result时为什么保守判断未知？不能因想补齐日志而重发写工具。
