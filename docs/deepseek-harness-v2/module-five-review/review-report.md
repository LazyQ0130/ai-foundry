## 关键技术判定

1. H17把Session append解释为内存事实接纳，未许诺物理耐久。Surface与业务Projection各有派生机制；Header不占普通事件位置。H18区分通用Handle契约和JSONL具体write/sync，Session/服务flush先排空路由缓冲，直接handle.flush不替它完成前一步。
2. 普通Fork继承包含切点的合法历史前缀，开放Turn可经子分支合成闭合；不会重新执行历史工具，也不自动产生运行时父子关系。官方说明中的拒绝开放切点概括与源码/测试不一致，详列于来源差异，而非改写历史证据。
3. compaction/*是审计事实，单独的user Surface替换消息才承载后续模型摘要。原日志仍在，工具配对约束仍适用；逐事件提交可能部分成功，不能宣传成失败全部回滚。
4. Retry在当前Step的Attempt边界重新prepare并派生当前历史，不重接输入或重跑整Turn工具。normal的provider/policy预算与Basic预算独立；新增两个注册顺序反例及预算耗尽委派均通过。always不保证成功，retry计划不等于持久屏障或已开始请求。
5. cancel是合作信号；已启动工具需结算排空，whenIdle不是业务成功或落盘保证。无result不能推出无效果，UNKNOWN不等于撤销，恢复不自动重放旧工具。物理尾修复、Session语义修复、新Agent生命周期和活请求Retry分别处理。

真实同一Agent贯通探针包含工具1次、压缩、失败Attempt、Retry、JSONL保存32事件、新后端实例Resume后继续至43事件；5次普通模型请求与1次摘要辅助请求均为受控Adapter。每个请求的事件前缀及派生节点见统一模型和综合题A。它加强D级证据，未升级E或实际崩溃认证。
