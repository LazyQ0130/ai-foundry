## 重复是否增加理解

H17的flush反例用于区分内存与落盘；H18加入真实Handle与文件；H19证明压缩后仍能落盘重建；H20把失败Attempt/取消/未知结果加入恢复。Surface在H17是读模型，在H19成为有损输入管理，在本轮Q14成为逐次请求可重建性。tool/result从配对进入保守恢复，再进入不可逆效果判断。这些是逐步增加条件的重复，适合保留。

容易造成混淆的是同一术语出现在不同承诺层：Seq与Offset、Session与Agent恢复、Usage与启发估计、retry计划与started、whenIdle与flush。统一模型的八层表与综合题按这些错因评分。五道跨课题共48分，单背术语不能通过事件输入推导、预算算数或安全恢复决策。
