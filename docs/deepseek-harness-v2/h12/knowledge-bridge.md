# H10–H12衔接与重复审查

H09建立实例与归属；H10确定工作边界；H11推导输入；H12解释响应如何逐片形成内容并结算。沿同一README任务，各课交不同产物，不按同一个执行图重复讲四遍。

| 前课已学 | H12最小复习 | H12新增产出 |
| --- | --- | --- |
| Stage3流式页面/HTTP、Stage4工具往返 | 一次性文本与流不同；工具结果必须回交模型 | 可运行AsyncIterable三份状态，网络帧与公共分片分开 |
| H09 Registry/Factory/Handle | 已创建Agent可共享服务，Turn结束不销毁 | 一个实例的响应Attempt身份/实时revision，不为每片造Agent |
| H10 Turn/Step/Attempt | 重试可以仍在一个Step；先结算Assistant再工具 | 逐片index、组装保留规则、committed/abandoned的匹配事实 |
| H11准备/历史/工具声明 | Loop请求通过派生messages与tools输入，不单列system | Runtime准备的一次性/代次绑定；Adapter原生协议映射及规范化边界 |

H10已介绍实时流位置与取消半句，本课只用短回顾接入；实际新增是BlockAssembler、紧凑记录及完整终态对照。H11已经运行prepareCall路线能力，本课解释该方法内部的捕获、默认、回调、配置核对，未重讲Prompt Section/Variable排序或Context刷新。实践D复用工具往返的情节，但检验重点变成分片/组装/结算seq，而不是再数一个Turn。
