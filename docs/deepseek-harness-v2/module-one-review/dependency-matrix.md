## 复习是否有帮助与独立学习价值

四课分别产出职责图、导航路线、执行轨迹、启动配置判断，目标不互相替代。重复“提议不是权限”时分别用于职责、接口、时序与组合边界；保留它比删除成一句交叉链接更有教学价值。开头 3–8 分钟回忆是设计意图，不是实测时长。

H01/H03 在主线保留足够旧知识说明；H02 可选语法卡解释 type/interface/implements；H04 主线与折叠卡区分环境文本、读取者与进程。原课入口均为可选，现有权限不变，未购原课的等效基础读者也可做独立 Mock。是否每位学员都能独立迁移，仍须试读。

Stage 4 本次核读重点：`s4-l1.md` 的“刚才究竟发生了什么/让循环知道何时停下”；`s4-l3.md` 的 HMAC 与重放；`s4-l5.md` 的 Workflow/取消/资料注入；`s4-l6.md` 的三表/唯一约束/安全 checkpoint；`s4-l7.md` 的行为硬门槛；`s4-l8.md` 的部署证据边界。没有将这些项目的具体机制说成 Harness 的相同实现。
