# H08 → H09 衔接说明

这是未来研发输入，本轮未开始H09。

学员应带走：五层配置计算及字段消失位置；Entry/Plugin定义/Fiber的区别；稳定ID普通更新、禁用再启用与依赖恢复的真实轨迹；源文件、组合配置、effective配置、服务状态的分账；三类故障与精简组合取舍。

下一问是：“现在我们知道Agent能力怎样被装配起来，下一步需要研究运行中的Agent实例如何创建、持有和销毁。” H09需重新核锁定Commit的AgentRegistry/Factory/Handle、调用者所有权与发布/失败收尾，不能把配置树组装误当Agent实例创建事务。

继承的边界：PENDING不等于失败；已显式DISPOSED不复活；普通restart不是磁盘新代码；重组应用后失败不保证旧配置回滚；资源清理不是外部副作用撤销；Session接受事实不自动等于磁盘flush。稳定配置ID也不是AgentId。

H08真实测试层：教学子集、Cordis/Loader、隔离Profile/App Boot；真实五模板仅解析。原生HMR模块替换、完整官方应用/套件、真实Provider、磁盘恢复、学员试读与独立外审仍未完成。后课需按自身目标另建证据，不能继承不存在的PASS。
