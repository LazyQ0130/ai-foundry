## 真实源码与运行验证

28 个正文固定范围、24 条关键断言、37 个文件逐字节匹配固定 Git blob，并保存 SHA256。运行时加载的 Cordis/Cosmokit TS 文件全部在核对范围内。AST 另核四组类/成员归属，包括实际 `LlmRuntime.prepareCall`；正则、行号和 AST 不独自证明语义。

官方工具测试与组合测试只选读 setup/action/assertions。9 项是本课程作者编写、实际执行 vendor Cordis 的库级测试：2 项普通接口实验，7 项 Cordis 行为。提供方两种顺序各恰好一次输出；类型存在但未注册仍 PENDING/零输出；遗漏 inject 实际抛错；兼容实现产生不同输出；异步提供方激活前不调用；重复登记失败。另有删除 inject 的子进程变异，非零退出；缺依赖 demo 子进程退出0而无问候。

不是只做类型检查：类型负例证明编译期形状检查，发射文件证明声明擦除，真实运行证明服务可用性与入口行为。没有完整官方 Vitest、Loader/YAML、Profile boot 或整个 Harness 集成通过的声明。文档与实现的精度差异见源码清单；尤其不将“注册立即”误说成异步初始化完成。
