H07→H08的关键链已明确：配置重组定位Entry，必要时更新/退出运行；旧资源按其Fiber归属清理，重新运行登记新资源；服务失去使依赖Consumer清理并PENDING，恢复可重跑原Consumer。普通config更新可同Fiber，禁用再启用新Provider Fiber。清理是可靠重载的重要基础，不自动取消任意在途回调、迁移业务状态或回滚外部写入。
