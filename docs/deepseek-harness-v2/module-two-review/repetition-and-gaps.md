# 跨课重复、知识跳跃和易懂程度

依据是四份完整正文、全部代码块/实验/答案和图源，不仅是质量报告摘要。依赖全表见 dependency-matrix.md；本页给教学处置。

| 交接/重复 | 实际新增任务 | 判定与处置 |
|---|---|---|
| H04 配置模板→H05 插件 | 从“清单从哪来”转为“谁提供能力、谁消费” | 合理复习。H05 不重教参数/环境优先级 |
| H05 服务→H06 服务与事件 | 明确能力调用与可扩展参与点可组合 | 合理：事件也可返回结果，不能用有无返回值粗分 |
| H05 类型擦除→H06 Events 擦除 | 同一编译/运行边界落到监听器 | 保留，两种常见错误不同；没有复制同一个完整实验 |
| H05 inject→H07 inject 变化 | 一次加载条件升级为持续可用性跟踪 | 必需复习；Consumer 身份保持是新内容 |
| H06 Waterfall→H07 on 清理 | 从当次分发转为插件卸载后未来/在途回调 | 必需；无需重讲全部五模式 |
| H07 Fiber→H08 Entry/Fiber | 将运行身份与配置身份分开 | 必需；配置 ID 稳定不承诺 apply 次数不变 |
| H07 失败状态→H08 配置失败 | 从加载失败扩展为解析前/应用后/Schema 拒绝 | M2-01/P1，已补加载阶段限定与短反例、改图源 |
| H04 Profile→H08 Profile | 模板导航升级为算法、真实树与更新 | 合理，minimal 例外需短复现；不重演 CLI 启动全程 |
| 四课证据/权限边界 | 每课运行范围不同，复制代码时需独立可见 | 保留必要边界，不因“说过”删到外链；集中报告进一步分账 |

没有确认需要整段删掉的无教学价值重复。判断依据是每次复习是否改变学员要交的产出，而非词频；本轮不把重复出现的 Plugin、inject 或“未执行完整应用”当作编辑缺陷。

## 三个难点的输入、过程、输出与反例

| 难点 | 输入与过程 | 可观察输出 | 错误/边界与可理解性判断 |
|---|---|---|---|
| H06 Waterfall | 选中的 A/B 监听与默认主体；next 进入剩余回调，返回逆向包装 | 2→20→21；三层 51；拒绝仍返回已进入外层 | 漏 next 主体0次；漏 return 可主体1次却丢值；重复 next 可能主体2次；异步 catch 要 await。两层变量表、图三与真实轨迹互证，结构充分；不能用测试通过推断已理解 |
| H07 Fiber/Effect | 一次挂载、所需服务、on 与原生资源、释放门闩 | 六状态及原因；旧监听撤销、连接夹具关一次；依赖恢复同 Consumer | 逆序启动/并发完成、重复清理不加入在途任务、清理失败仍 DISPOSED、卸载不取消已开始回调。主线短程序和配对表降低抽象；新增 Schema 对照补跨课边界 |
| H08 Patch/HMR | 有序 Bundle 文件→Profile→Home→启动 CLI 快照；Entry/Fiber 与协调入口 | 每层完整 config、最终树、身份与服务值 | 深合并错误、无目标/name 保护、缺依赖、坏解析、应用失败、Schema 拒绝、尽力恢复。两处停顿明确交中间结果和三列状态；缓存实现仍重，首遍按五站路线读，异常 catch 可作第二遍深读 |

## 类比、源码与设计判断

H05 用项目助手“把实现写在同一类内/按契约替换”，不承诺插件一定降低全部成本；H06 通知/逐个询问/环绕的类比随后给具体等待和值判据；H07 “资源与退出配对”不表示框架能猜任意库的释放；H08 “装配清单修订”立即排除 Git diff/逐行拼接，minimal 不画成 base 子层。图注均说明省略范围。

源码阅读路线与调用时序分开，长完整程序折叠，默认主线有输入、解释与预测；未发现连续多段未解释的官方源码粘贴。H08 折叠内完整夹具长达数十行，抄录仍可能重，应优先复制受测随课文件并逐段追当前问题，不要求通读辅助内部算法才算完成。没有删掉失败分支来压时长。

“为什么采用此设计”的成本收益明确署作者分析；“实际发生什么”由固定实现/运行分账。H05 普通参数注入、H06/07 的门闩/时间源、H08 平面模拟器都有简化标签，不当官方 App Boot 成功。测验 Q09/Q14 专门要求学员降级证据陈述。

仍待试读：Promise 返回对象与兑现值能否无提示分开；H07 同一对象重载和新对象重挂能否准确画图；H08 原始/有效/运行三列是否仍需更多口头引导。不是确认 P1，不以作者猜测机械重写四课。可先用测验 A/B/C 收集错误类型、提示次数和时间，再决定有针对性的下一次修订。
