## 已确认修订的精确边界

M2-01 不表示原 H07 的初始配置失败实验错误。`_reload()` 包围 resolveConfig/入口执行并走卸载，真实初始失败测试仍正确；`update()` 则先写 `_config`，ACTIVE 分支同步校验通过后才进入 internal/update。因此失败阶段必须写在表、图和题目中。新增探针输出 `{raw:'bad', effective:1, service:1, state:'ACTIVE', cleanups:0}`，再提交有效2才清理并重跑。

未发现要改官方实现、实验期望或五模式/Patch 算法的依据。旧课源码清单记录原交付范围，本报告作为新增限定，不重写历史验证记录。版本差异策略见增补标准：此处结论只针对锁定版本，不能直接泛化为其他 Cordis 稳定版或当前主分支。
