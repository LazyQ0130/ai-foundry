# H20 → H21 前置与边界

H20完成后，学员应能分清历史事实、持久前缀、当前Surface、活跃Agent与运行取消；解释Handle所有权、同Step新Attempt、可取消退避、已启动工具排空、未知效果保守修复。应能从X的Seq8～17推导不同控制边界，不只背诵错误码。

H21蓝图的独立问题是Subagent activation：谁拥有创建/准入/执行/结果delivery、运行时父子与历史谱系怎样区分，spawn与fork怎样准备上下文，如何等待后代退出。H20只交接这些问题所需的所有权和协作取消，不实现完整父子树、SubagentRuntime或团队编排。

不要把parentSession当作当前parentAgent，也不要因parent cause词汇存在就宣称H20已经验证完整后代取消。某子任务不响应signal时，父级是否等待、如何处理结果和释放，由H21的实际Provider/activation协议继续研究。Jobs、Goal、Schedule留H22，载体和远程重连留H23，完整系统证据方法留H24。

可复用的H20证据：B:handle-dispose/delegated/tool-after/parallel；C新实例恢复；X真实保存前缀与保守修复。不得升级为跨进程多Agent或E级。真实Provider成本/缓存、全平台/断电、真实学员和独立外审仍待独立验证。
