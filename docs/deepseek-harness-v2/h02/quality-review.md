## 概念七步结构审查

| 概念组 | 问题与通俗场景 | 定义、真实证据与类比边界 | 检查理解 |
| --- | --- | --- | --- |
| Monorepo / Workspace / Package | 多部门协作；园区、成员册、名称牌与窗口 | 根清单、pnpm 成员、包 name/exports；仓库不是一个包，成员不等于挂载，工作区有业务同名词 | 两级路径练习及定位 A |
| Entry Point / Build Artifact | 从哪个窗口进入；图纸到零件 | bin/lib、浏览器模块脚本、包 exports、source paths；导出不等于执行，paths 不自动改写任意 Node 行为 | 入口选择、没有 lib 时先判断源码还是产物 |
| Dependency / Module Boundary / Dependency Graph | 需要规范、施工先决项、运行协作是不同关系 | imports、项目引用、服务选择与方法调用；导出边界不是 OS 隔离，图先定义节点与边 | 六条分类与三层图；peer 图例反例 |
| Runtime / Host / Client | 沿用 H01 运行职责，补前台终端与后台系统 | host/client README、main.ts、两套 aggregate；同机可分角色，编译单元不是机器或权限边界 | 根 solution 与实际配置阅读，R4 的运行期条件 |
| Definition / Provider / Consumer | 诊疗约定、实际诊室与使用流程 | ToolExecutor、NativeToolExecutor、默认循环；角色可在一包合并，不要求三个进程；Provider 不限于模型商 | A 的接口/实现/消费方字段与理由 |

不以粘贴概念手册代替讲解。TypeScript 语法另用可选收据例子提供最小阅读能力；明确 HTTP API 接口与 TypeScript interface 不同。发射探针只证实 type/interface 消失、实际使用的函数导入保留，未冒称官方或完整语义类型检查通过。

## 技术审阅与已处理问题

1. 根 `workspaces` 与 pnpm 清单不是逐字相同：正文指出后者额外列 benchmarks 和 Python runtime，不将前者冒充完整成员真值。
2. 包名、源码路径、发布入口不同：同时给 name、exports、paths 的真实证据；不把 paths 当任意 Node 运行期加载规则。
3. 原生执行器 `apply` 是模块导出函数：正文与图采用正确表述，不写成类静态方法。
4. 工具服务经选择对象调用具体提供方：原生路径有配置前提，不能推广到所有 scope 或入口。
5. 测试位于 agent-loop，原生执行器包没有因此被虚构出相邻测试文件。只描述所读用例实际断言的注册表/选择/工具呈现，不扩大到所有安全或调度性质。
6. 官方 module-graph 明确只画 peer；没有当作完整 import 或调用图。Host/Client 也保留共享、拆分配置与 Node 测试例外。
7. 图 1 把 util/test-support 放进 packages 范围，组合和启动用两个分组标识；图 2 全部仓库路径补上真实 packages 前缀，原生实现标到正确包，不留假路径。

蓝图中根路径门禁测试作为研发辅助静态核对；正文改用与功能主线直接相关的跨包执行器用例。固定 Git 对象、行范围与六张卡片逐行检查结果见 [source-check.json](evidence/source-check.json)。它们是静态事实检查；作者另读了注册、选择、转交和断言，没有从字符串匹配自动推出语义正确。

## 教学可读性审查

开头承接 H01 的六行职责，不重复四词全套解释或日志审批实验。主线先场景后目录、先清单后入口、先契约后实现，最后再解释三种图。三张图各处理一个认知任务，Host/Client 用小文本示意，避免再添加一幅密集架构图。

五个核心精读文件与定点辅助文件在清单中分别列出。全课引用范围多于精读文件数，因为导航课程需要确认清单、配置、边界、文档和测试，但不要求逐一通读。`ToolExecutor` 的复杂失败/并发契约只定位，明确留后续细读。

两项练习有完整答案与解释，学生复制正文程序即可完成，不依赖购买其他 Stage、下载未注册资源、API 费用或 GUI 验证。脚本对特定指定路线做事实核对，其他合理测试选择不因此被认定为错误；练习的固定范围在答案中说明。

作者审读认为主线连贯、术语有具体落点；仍存在真实试读才能判断的难度：包管理 workspace 与业务 workspace 的同名区别；接口类型、提供方对象和运行期调用的转换；看到 peer 图后能否主动读图例。不能把本段作者判断当作学习效果已验证。
