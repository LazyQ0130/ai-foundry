## 概念与认知负担审阅

| 概念 | 先解决的具体问题 | 例子与定义连接 | 防止的误解 |
| --- | --- | --- | --- |
| Session / Agent / Lifecycle | 记录还在，执行者是否还在？ | 工作记录与当前执行者；共享身份、setup 后登记、每轮后 idle、拥有者释放 | 实例是线程；会话存在就一定后台运行；每个 Turn 结束即销毁 |
| Inbox | 消息收到后，何时交给模型？ | 待办篮；next-turn 与 next-step、claim、spliced 事实 | 已发送=已接纳；agent/ 前缀必是实时 |
| Turn / Step | 为何一条用户任务请求模型两次？ | 一次处理工作与期间判断；官方零/多步骤定义，重试尝试例外 | Turn=API 请求；Step=工具次数；Step 数=网络计数 |
| Prompt Assembly / Model History | 模型需要的不只是一句话 | 交接要求与从记录选出的有效材料；系统渲染、deriveMessages、请求快照 | 日志原样全发；文件名自动带内容；每步又追加用户消息 |
| Stream | 界面为何先出现半句话？ | 逐页接收；异步块、实时帧、完整结算与 seq | 每块是一个 token；看见=提交=落盘 |
| Tool Call / Result | 领料单为什么不是回执？ | 助手提议结算后交工具系统；调用起点、检查、结果关联 | tool/call=主体成功；工具中的指令能升权 |
| Event Log | idle 后怎样知道刚才发生什么？ | 顺序经过与最终照片；派生、重建与持久化分层 | 有日志就能恢复 CPU 或回滚外部操作 |

重要概念均有通俗解释、同一场景、技术定义、固定证据与误解；Session、Inbox、Turn/Step、请求材料在相邻位置有理解提问，其余用四道可折叠思考题复核。不单独插入整份术语手册。Prompt/消息表面/重试只讲本课必要层，不展开实现算法。

## 本课范围的主动收束

- H09 接过实例与会话身份，详读注册、所有权与释放；H03 只给生命周期轮廓。
- H10 接过 Turn/Step/Inbox 草图，详读竞态、唤醒和阶段状态；H03 不把每个入口都展开。
- H11/H12 接过有效请求材料与流结算；投影、缓存系列、Provider 协议留后续。
- H13–H15 接过 tools.execute→原生执行器→共享流水线；审批和权限只指出边界，不实现全套。
- H17/H18 接过事件/消息/flush 区分；事件重放不等于进程续跑，不提前教学恢复算法。
- H20 接过 aborted/error/attempt 与重试可能性；不在这里承诺统一超时或重试次数。

## 交给 H04 的内容与接口

H03 先假定“Agent 与作用域已就绪，模型适配器、工具系统和会话记录接入已具备”。H04 应回答这些前提如何经运行入口、环境与 Profile 成立。建议先接 H02 的 `apps/cli/src/bin.ts` 与模板/组合地图，再依据蓝图核对 Profile 解析、配置和启动；不能直接把图 2 的每次 Step 画成重新加载 Profile。

交接产物：学员一张标明两种记录线的主线图；九场景计数；一条工具结果改变后续请求的反馈证据。下一节开场可问“为什么相同 Agent 接口在不同入口看到不同能力”，本节不生成 H04 正文、代码或图。

H03 本轮扩充为三张图、九场景与四道思考题。暂估 100～140 分钟，可分“概念与两案例”“源码与实验”两次学习。真实时长、首次阅读能否独立画图、零 Step/重试例外是否过难，均待学员试读；技术通过不替代这些结论。
