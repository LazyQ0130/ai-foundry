## 技术审查与已修订项

1. Turn 起点在领取与接纳前；首次 reject 的零 Step 路径有专门图、官方测试和 Mock。
2. Step 包括模型与相关工具，不是工具计数；重试可在同 Step，多 API 尝试不等于多 Step。
3. 准备适配器先于接纳消息提交；header/context 仅按需记录，首次用户消息不在每步复制。
4. 成功助手消息先结算，再分派工具；工具起点日志先于检查，不能据 tool/call 宣称主体已运行。
5. `isError` 工具结果可进入下一 Step；批次调度异常与普通错误结果分开。工具失败后诚实回答可令循环 completed，但用户读取目标未达成。
6. 实时 chunk、Session 接受、持久存储 flush 分层；`agent/inbox/spliced` 是 `agent/*` 总体概括的真实例外，取消有安全前缀时可为 interrupted message。
7. 初稿短代码中的变量名、preStep 参数形式在逐字校验时发现不符，已替换成固定源码原句；未把近似代码保留为官方摘录。AST 检查使用实际 `dispatch` 与局部 session 对象名，不以想当然调用名凑通过。
8. 真源码探针首次构造的助手消息未附模型 source，重建校验拒绝；已按官方消息契约补齐 mock provider/model，再通过。这个探针发现的是测试夹具缺项，不是上游恢复缺陷。
9. 图片浏览顺序为包含关系→完整主线→时序对比，对应资产 ID 02→01→03；QA 截图已按实际图片 src 命名，不按页面第几张错存。

28 项关键断言、48 个固定链接、22 个官方文件已核 Git blob。六项 AST 定位核对与实际实现分支、官方测试断言选读交叉检查；没有仅凭匹配关键字判断调用链。完整官方 AgentLoop 测试未执行，报告不虚报。

## 实验与交互的实际检查

独立 Mock 包含 direct、tool、multi、reject、tool-failure、cancel、model-error、timeout、prepare-error 九场景。十项行为测试检查：边界嵌套、消息接纳位置、工具结果真实参与第二次判断、请求快照不被后续修改、提交先于 end 通知、错误回读、取消不追加工作、准备失败无模型消息、恶意资料不增加工具以及未知场景报错。固定故障不冒充真实网络超时；实验没有 Harness 全量 schema、审批、并发、持久化或重试实现。

另运行四项**实际锁定源码**内存库探针：实时块先于助手提交；真实 settle 先追加后 committed end；detached Session 重建派生消息一致且排除 attempt/边界；追加拒绝发 abandoned。它们不能代替完整 AgentLoop、真实 Provider、磁盘写入或安全测试。

实际平台 parser/SSR 解析五字段、四个唯一任务键、三图、八个默认关闭的折叠区，完整实验代码和 JSON 答案与文件一致。既有 Renderer 九项回归通过。本轮无产品路由或权限集成，不运行会改写目录/ZIP 的整站发布构建。

浏览器以真实 React createRoot 挂载 LessonMarkdown，使用实际平台 CSS，检查 1440、390、320 三宽度：无页面横向溢出；图片 alt/图注/原图 popup 可用；键盘 Enter 可展开关闭；完整程序与 JSON 复制准确；四道思考答案可展开；长实验代码在内部横滚，320 时滚动范围 962px；静态整课预览三图可加载，未保留无挂载时失效的复制按钮。
