# AIFoundry Learning Visuals V2｜视觉规范

## 教学目标

每张图只解释课程中的一个核心技术关系。优先用节点、分组、对象状态和有方向的箭头表达；详细说明仍留在课程 Markdown。图内仅使用必要的中文与英文技术标签，不放真实账号、密码、连接串、Cookie 值、Token 或完整付费正文。

## 构图与制作

- 蓝色表示请求、代码或主流程；蓝绿色表示回读和有效状态；橙色表示等待、未知或尚未隔离；红色只表示拒绝或错误。米白色背景和深蓝文字保持系列感，允许不同课程使用不同构图。
- 让数据库、服务端、浏览器、文件或状态成为图中的视觉主体。并行角色分成独立通道；不同数据来源必须分开；时间顺序和请求回程用明确箭头表示。
- 优先用 image_gen 一次生成完整信息图，不再使用“空白底图 + 大面积文字框”的 V1 工艺。遇到复杂技术关系或反复出现的错字、错箭头时，可改用从零整体设计的 SVG；本轮 `s2-5-02` 使用该方案，源文件为 [s2-5-02.svg](teaching-visual-v2-sources/s2-5-02.svg)。
- 不使用人物、机器人、无关装饰、伪造的操作截图或三层大段文字模板。示意性的浏览器、代码和数据库图形要和真实软件截图区分。

## 选定样板

用户按 S2-3-02、S2-5-01、S2-6-01、S2-8-01 的顺序选择 **B、A、A、A**。四张正式图由对应完整分辨率的 PNG 候选转为 WebP，样板原图与对比总览仍保留在 [teaching-visual-v2-samples](teaching-visual-v2-samples/README.md)。

## 尺寸与课程集成

- 正式成品保持原图号与课程 Markdown 插入位置，输出为 `public/course-media/stage-1/` 或 `stage-2/` 下的 WebP。现有 Alt 和 Caption 描述实际教学关系。
- 大多数成品约 1672 × 941，SVG 备用图为 1600 × 900。按约 335px 课程显示宽度检查主节点、文字和箭头；较细的技术标签可由用户打开原图放大，正文不能依赖它们传达关键关系。

## 复核重点

逐张核对中文、技术词、节点数量、箭头方向和课程段落。特别检查迁移只建结构、POST/GET 对数据库的读写、Session 位于数据库、2.5 尚未隔离 Resource、2.6 的服务端 ownerId 与 404、生产数据库独立于 GitHub 和 Vercel Build。生成图出现虚构字段时应删除或重做，不以测试通过代替视觉校对。
