## P0 · 直接压转化的三条

### 1. 付费墙页面几乎空白（最高优先级）

实测 `/lesson/stage-1/s1-l2`（已登录、未购买该阶段）→ 截图 `01-paywall-blank.png`

页面全部内容：

```
1.2 把「我想要」说成 AI 能做对的需求
阶段 1 · AI 原生开发入门 · 30 分钟
该课程属于 阶段 1，购买 / 开通后即可学习
[查看购买 / 开通方式] [返回阶段]
```

- 面包屑、右侧栏（学习任务清单 / 卡住了？获取帮助）全部消失，整页 2/3 是空白。
- 用户此刻的意愿是最高的（他已经点进来了，想看这一课），却只被弹回价格页。

**建议方向**：这一页不该只是"拦截页"，而应是"课程预告页"——课程简介 / 学完能做什么 / 该阶段价格与权益 / 「先看免费的第 0 课和 1.1」/「加微信开通」入口，并保留右侧栏的学习辅助。

### 2. 购买弹窗：真正的动作（扫码）在折叠线以下，主按钮还抢了焦点

实测 1440×820 视口点「立即购买」→ 截图 `02-purchase-modal-fold.png`（二维码只露出上半部分）。

弹窗内容顺序：`价格 → 退款说明卡 → 4 步说明 → 二维码 → 注册手机号 → 免责说明 → 「已付款？查看开通指引」→「查询是否已开通」→「前往个人中心」`

- 二维码要滚动才看得全；手机上要滚两屏（截图 `07-mobile-modal.png`）。
- 「已付款？查看开通指引」是**实心蓝主按钮**，视觉权重高过二维码，但点了只弹出一段解释文字，没有真实动作 —— 用户会以为流程在这里。
- 本机 `.env` 的 `WECHAT_CONTACT` 为空（`.env.example:11` 也是空）。若线上同样为空，**手机端用户没法扫自己屏幕上的二维码**，也没有微信号可复制。这一条需要确认线上配置。

**建议方向**：二维码提到价格下方（首屏可见）；退款/免责说明收进折叠或小字；「已付款？查看开通指引」降级为文字链接；手机端确保有可复制的微信号文本。

### 3. 首页没有任何直达「免费体验」的入口

- 首页所有 CTA 目标：`/path`、`/stage/stage-1`、`/about`、`/pricing`（`src/pages/Home.tsx:52/56/254/321`）。
- 而第 0 课与 1.1 实测**未登录就能读全文正文**（这是很值钱的免费钩子）。
- 现状：陌生人从首页要看真实内容，得走 首页 → 阶段页 → 开始免费体验 三跳。

**建议方向**：首屏加一个「免费试学第一课」直达 `/lesson/stage-1/s1-l1`。对抖音引流来的用户，这是最低成本的第一次价值接触。

## P1 · 体验明显不顺畅

### 4. 禁用按钮和可用按钮长得一模一样

- `src/index.css:67-90` 的 `.btn / .btn-primary / .btn-outline` 都**没有 `:disabled` 样式**。
- 结果：学习页「标记为完成」在 0/5 时仍是实心蓝（截图 `04-disabled-button.png` 右栏），未登录时任务清单的勾选框也看不出被禁用（`src/pages/LessonPage.tsx:296` `disabled={!user || saving}`、`:318`）。
- 桌面端靠 `title="请先完成并勾选全部学习任务"` 兜底，**触屏设备完全看不到这个提示** → 点了没反应 = "网站坏了"。

**建议方向**：全局给 `.btn:disabled` 加 opacity + `cursor: not-allowed`，并把「还需勾选 x 项」做成常显文字而不是 title。

### 5. 浏览器标签标题全站不变

全仓 `grep document.title` 无任何结果，`index.html:11` 只有一个固定标题。
多标签页、收藏夹、分享链接、浏览器历史、SEO 全部显示同一句话。
**建议方向**：按路由写 `document.title`（如「1.2 把「我想要」说成 AI 能做对的需求 · AIFoundry」）。

### 6. 未登录的课程目录顶部显示「总体进度 0%」

截图 `03-anon-catalog-progress.png`：访客看到「总体进度 0% / 已完成 0 / 29 课」+「继续上次学习」。

- 「0%」对没有账号的人没有意义，传递的是"我落后"而不是"这里有什么值得学"。
- 「继续上次学习」对没有上次的人是个空按钮。

**建议方向**：未登录时把这块换成免费体验引导（对齐第 3 条）。

### 7. 登录 / 注册页是全站最"素"的一页

截图 `05-login-page.png`：1440 宽下左侧 2/3 纯空白，只有一个白卡片 + 三个输入项。

- 首页做得相当精致，登录页的落差很明显。
- 而注册是「抖音 → 站点 → 加微信」链路里**必经的一环**，这里既没有价值复述（会学到什么 / 学员产出），也没有「先免费试学」的出口。
- 次要问题：2026 年仍用「手机号 + 密码」注册，且页面自己写着"目前手机号不验证归属"——用户会犹豫要不要填真号。

**建议方向**：左侧补价值区（一句主张 + 3 条产出 + 免费体验入口），右侧保留表单。

## 已验证没问题（别改坏）

这些是实测通过的，改动时不要顺手"修"：

1. **390px 全 12 条路由零横向溢出** —— iframe 探针实测 `scrollWidth === clientWidth`（375/375）。首页那两个被 `overflow-hidden` 裁掉的元素是装饰性模糊光斑，属于有意为之。
2. **未登录可读免费课正文**（第 0 课、1.1 全文），付费课才有拦截 —— 免费钩子的实现是对的。
3. **图片都有 `alt` + `loading="lazy"` + `referrerPolicy`**（`src/components/LessonMarkdown.tsx:55-58`），并且图注自动取 `title || alt`。
4. **空态 / 错误态 / 加载态都带 `role="status"` / `role="alert"`**，Esc 关闭、焦点陷阱、`aria-modal` 在弹窗里都实现了（`src/components/AdminControls.tsx:10-34`）。
5. **控制台干净** —— 除 React Router v7 future flag 外无任何报错。
6. **价格算术正确**：99+199+269+299 = 866，`¥599` 与「立省 ¥267」一致。
7. 首页「首页不展示价格表、只留一个价格锚点」的设计意图保持完好。
