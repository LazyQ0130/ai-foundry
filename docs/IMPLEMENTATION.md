## 个人头像与资料优化（2026-09-26）

- 顶部账号入口与个人资料卡共用圆形头像，支持昵称截断、加载失败回退；资料卡支持头像裁剪、更换、恢复默认和昵称保存反馈。
- 本地选择 JPG/PNG/WebP 静态图片，限制 5MB / 2500 万像素；圆形预览支持拖动、方向键和 1–3 倍缩放。裁剪为 512×512 WebP 后提交，服务端独立校验、重新编码并限制存储大小为 300KB。
- `PUT /api/me/avatar` 接收 `image/webp` 二进制（上限 1MB）；`DELETE /api/me/avatar` 恢复默认。两个接口返回原有 `User` 格式。`GET /api/me/avatar?v=版本号` 仅返回当前登录用户匹配版本的图片，使用 `Cache-Control: no-store`。
- 新增一对一 `UserAvatar` 表，图片单独存储，不进入普通用户查询或 JSON；用户记录继续保留 `avatarUrl`。替换和恢复默认在事务中完成，不保存头像历史或原图。
- 部署顺序：安装依赖、`npm run db:generate`、`npm run db:migrate`，然后构建和发布服务与前端。迁移 `202609260002_user_avatar` 只新增表和关联，旧账号无需回填。不需要文件上传目录。
- 自动验证：`npm run verify` 19 项测试通过；新增头像测试覆盖持久化、重新登录、隔离、版本替换、恢复默认、错误格式、动图、超限像素/字节及昵称兼容。`npm run test:production` 通过。
- 浏览器验收：真实账号完成选图、键盘缩放/移动、保存、刷新、恢复默认、Escape 取消与焦点恢复；确认长昵称和组合 Emoji 默认头像、加载失败回退。390 / 768 / 1280px 视口检查通过；桌面效果见 `preview/profile-desktop.png`。验收账号在完成后禁用，未改动日常账号资料。

## 可重复验证

```sh
npm run verify
npm run test:production
```

`verify` 包含前后端类型检查、前后端构建、真实 PostgreSQL 集成测试、内容一致性检查、前端正文泄露检查。测试使用连接数据库里的独立 `aifoundry_test` schema，不清空数据库，也不删除日常账号。多次运行会保留可追溯的测试数据。

`test:production` 使用编译后的 Node 服务，临时监听本机 3081，验证 SPA 路由、Secure/HttpOnly/SameSite Cookie、登录退出、CSRF 和私有文件隔离，完成后关闭自己启动的服务。
