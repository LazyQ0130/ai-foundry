# AI Research Workspace — engineering bootstrap

This is the student starting point. C1 begins with product discovery and `docs/product-brief.md`; C2 creates the architecture decision, database, auth, workspace and first persistent research task.

The bootstrap contains only Next.js, TypeScript, ESLint, a test command and an empty application shell. It has no product schema, account flow, research UI, AI integration or storage integration.

Requires Node >=20.19. Run `npm ci`, `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`.
