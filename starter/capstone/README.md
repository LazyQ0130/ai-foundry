# AI Research Workspace — engineering bootstrap

This is the student starting point. C1 begins with product discovery: copy the blank files from `docs/templates/` to `docs/product-brief.md` and `docs/user-flow.md`, then write a one-sentence product positioning here. C2 creates the architecture decision, database, auth, workspace and first persistent research task.

The bootstrap contains Next.js, TypeScript, ESLint, a test command, an empty application shell and blank C1 templates. It has no completed product definition, product schema, account flow, research UI, AI integration or storage integration.

Requires Node >=20.19. Run `npm ci`, `npm run lint`, `npm run typecheck`, `npm test`, and `npm run build`.
